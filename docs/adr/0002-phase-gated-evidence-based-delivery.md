# Phase-gated, evidence-based delivery

**Status:** Accepted

Work proceeds through the 12 phases in the project blueprint, and a phase is complete only when acceptance criteria, phase tests, regression tests, cross-phase integration, quality checks, review, and a recorded evidence package all pass. This is slower than feature-driven development, but it prevents demo code, unverified claims, and silent regressions from being treated as progress.

## Consequences

- Implementation does not equal acceptance.
- A failed criterion or unresolved critical/high issue blocks the next phase.
- Each checkpoint must record commands, environment, totals, failures, review disposition, and next action.
- Historical results must be labeled as historical and never presented as newly executed.
