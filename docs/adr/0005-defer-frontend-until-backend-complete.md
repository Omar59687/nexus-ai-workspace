# Defer the frontend until backend core is complete

**Status:** Accepted

The frontend is deliberately deferred until core backend functionality and integration are complete. Building a UI first would lock in unstable API contracts and distract from the backend, memory, retrieval, orchestration, and security foundations that determine whether the product works.

## Consequences

- Phase 8 remains in the official roadmap but is gated by owner approval and backend readiness.
- API contracts should be designed and tested before UI work starts.
- No frontend technology choice is validated by implementation yet.
- Deferral does not renumber the roadmap.
